# ABS V62
сервер Brawl stars на версию 62 на Python!
## КАК ЗАПУСТИТЬ ABS?
1. Скачайте АПК файл игры 
https://drive.google.com/file/d/1dODQ_KkVvpdbauNLL6IOyBfGwWO2Cb93/view?usp=drivesdk
2. Распакуйте ZIP сервера 
3. Скачайте Pydroid 3 в гугл плей 
4. Зайдите в Pydroid 3 
5.  Найдите файл сервера "Core.py" и нажмите на кнопку запуска.
6. Готово! Приятной игры в ABS V62!
